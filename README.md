# What is this app 

A Flutter Android app built as a personal gift for a friend. (Caution: there're personal message ,daily reminder and birthday blessing in it you might want to replace them //they are all locate in lib/data/content.dart )

## What it does
Every step you take plants a flower on a live map. 
Walk more → grow a bigger garden.

## Features
-  Accelerometer-based step detection (no hardware step counter needed)
- Flowers planted along your real walking route on OpenStreetMap
- Daily garden that resets each morning
- Forever garden tracking all-time flowers, steps, and distance
- Daily calculus MCQ with instant feedback
- Walk history with stats

## Built with
- Flutter / Dart
- flutter_map + OpenStreetMap (no Google Maps API needed)
- SQLite (sqflite) for local storage
- Geolocator for GPS
- sensors_plus for accelerometer
